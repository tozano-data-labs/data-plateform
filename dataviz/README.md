# dataviz

Dashboards et visualisations consommant les tables `marts` de `transformation`.

## Règles

- Un dashboard ne lit jamais une table `staging` ni une source brute.
- Les requêtes et définitions de dashboards sont versionnées ici.
- Les captures et données d'exemple sont synthétiques ou publiques.
